# Fictional example build brief

Example corresponding to `preferences.json`; not an instruction to choose this
stack or feature set for everybody.

- **App:** My Trapper Keeper, fresh Cloudflare + Supabase web app.
- **Devices:** desktop and mobile browser; native mobile is out of scope.
- **People:** one authenticated owner, personal data private, no shared workspaces.
- **Modes:** Work, Life, All with explicit record scopes; unclassified inbox retained.
- **Modules:** tasks, action pocket, projects, resources, dated habit check-ins.
- **Omitted:** journal, fitness, nutrition, media, notifications, source integrations,
  recurring task generation, streak display and native mobile shell.
- **Organization:** PARA dividers, nested folders, named resource collections and Unfiled.
- **Dashboard:** next actions, Today, Past due, Recent wins, Coming up.
- **Tasks:** To do/In progress/Done/On hold; reopening clears current completion;
  action-link Open has no side effect; Clicked has five-second Undo.
- **Habits:** daily check-ins in UTC for this fictional example; explicit skips
  are neutral. No streak display; preserve actual check-in history.
- **Look:** original Ocean light cover and Galaxy dark cover; comfortable density,
  optional Calm, keyboard/pointer rearranging and bounded resize.
- **Preferences:** isolated by authenticated user/context; shared ordering omitted.
- **Starting data:** empty production store; approved fictional fixtures for testing.
- **Rollout:** remote preview; no public deployment or paid provisioning authorized.
- **First slice:** Work Home, editable task detail, one cover change and reload.
- **Acceptance:** domain/ownership tests, two-user denial tests, browser task actions,
  original/current check-in uniqueness, persisted preferences and accessible controls.
- **Open question:** actual user timezone must be confirmed; this example's UTC is not a user choice.

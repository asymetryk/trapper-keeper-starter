# Starter kit 1.0.0

An initial public, platform-independent recipe for building a personal binder
productivity cockpit with Airtable Omni or a coding agent.

Included: five-question intake, configurable PRD, schema and example profiles,
platform adapters/guides, original UI concepts, seven workflow diagrams,
acceptance checklist, optional migration strategy, one-file recipe, and a short
fictional-data browser demo of tab navigation and a light-to-dark cover change.

Fresh build is the default. The kit has no source-base integration dependency,
live account mappings, private operational history, imported records, privileged
credentials, hosting deployment, or automatic external sending.

The repository is MIT licensed. Images are concepts; the video captures a real
reference UI with fictional data. No generated consumer application is claimed
to be installed, deployed or universally compatible without testing.
